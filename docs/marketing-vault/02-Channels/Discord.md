# Discord

## Why this channel
Our own Discord is the retention and testimonial engine. Trial users who join talk to us; those conversations become the first real testimonials, the case study, and the Friday mock recordings that turn into Shorts. External Discords (bootcamps, system design servers) are a discovery channel where promo is usually forbidden but helpfulness is welcome.

## Our server — structure
- `#welcome` (pinned message from [[Social-Posts-Week1]] — download, pricing, trial explanation, DISCORD10)
- `#interview-prep` — questions, daily tip
- `#mock-rounds` — Friday 6 PM ET voice session, "Design a notification system" style prompts
- `#success-stories` — where testimonials come from; ask permission before quoting
- `#resources` — every new blog post
- `#feedback` — bugs and feature asks (route to the product backlog)

## Weekly cadence
| Day | Action |
|-----|--------|
| Mon | Post the new blog post in `#resources` |
| Wed | Daily tip / question of the week in `#interview-prep` (from [[Social-Drafter]]) |
| Fri | Mock round announcement (Thu) and session (Fri). Record with consent. |
| Any | Reply to every message within 24h |

## External servers
Listed in [[Communities]]. Rules: read the server rules first; help without links; mention Kraken only when asked "what tools do you use" and with disclosure. Never post invite links to our server elsewhere unless allowed.

## Testimonial ask (use verbatim)
> "Glad it helped. Would you be okay with me quoting that (first name or anonymous) on the site? No pressure."

Save consent messages outside the repo; record the quote in `07-Metrics` or the `Published/` note only after consent.

## What the agent produces
[[Social-Drafter]] writes 1 Discord message/day (tip, question, or announcement) into `05-Content/Queue/` with `channel: discord`.

## Measurement
Member count (manual weekly), mock attendance, `DISCORD10`, `utm_source=discord`.
