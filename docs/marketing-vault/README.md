# Marketing vault

Open this folder in Obsidian (File → Open folder as vault) or read it as plain Markdown. Start at `00-Home.md`.

Folder layout:

| Folder | Purpose | Who writes |
|--------|---------|------------|
| `01-Strategy/` | Positioning, personas, funnel, roadmap, compliance, competitors | Orchestrator, human |
| `02-Channels/` | One playbook per channel | Orchestrator, human |
| `03-Campaigns/` | Time-boxed pushes with goals and retros | Orchestrator, human |
| `04-Tasks/` | One note per task + `Kanban.md` | Everyone (agents only touch their own tasks) |
| `05-Content/Queue/` | Paste-ready drafts awaiting approval | Agents |
| `05-Content/Approved/` | Approved, waiting to post | Human |
| `05-Content/Published/` | Posted, with result | Human |
| `06-Research/` | Keywords, subreddit rules, communities, daily community digests, competitor changes | Agents |
| `07-Metrics/` | Weekly scorecards | Metrics agent |
| `08-Agents/` | Agent playbooks + conventions | Orchestrator, human |
| `09-Daily-Logs/` | One note per day, appended by every agent run | Agents |
| `Templates/` | Obsidian templates for each note type | Human |

Agents run as Cursor Automations on the GitHub repo and open one PR per run. See `08-Agents/Conventions.md`.
