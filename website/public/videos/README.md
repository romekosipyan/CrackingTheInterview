# Demo videos for the home page

Place your screen-share demo clips here:

| File | Shown as |
|------|----------|
| `you-screensharing.mp4` | **You, screensharing** — your view with Kraken Interview visible |
| `interviewer-view.mp4` | **What the interviewer sees** — the shared screen without the overlay |

Optional: override paths in `website/.env`:

```
VITE_DEMO_VIDEO_YOU=/videos/you-screensharing.mp4
VITE_DEMO_VIDEO_INTERVIEWER=/videos/interviewer-view.mp4
```

Recommended: MP4 (H.264), 16:9, under 30 MB each for fast loading.
